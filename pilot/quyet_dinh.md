# Biên bản trước và sau pilot

Trạng thái: **chưa triển khai**. Điền theo từng DN. Chỉ dùng bí danh.

| Chốt trước khi chạy | Giá trị / vai trò xác nhận |
|---|---|
| Mã DN, vai trò chủ dữ liệu, kế toán, người duyệt | |
| Phạm vi tài khoản, đơn vị tiền, số dư chốt, ngày bắt đầu/kết thúc | |
| Giấy phép sử dụng, người giữ khóa, hạn lưu và cách xác nhận hủy | |
| Ngưỡng tiền tối thiểu, định nghĩa thiếu tiền, thời gian báo trước cần thiết | |
| Đối chứng, MAE tối đa, giới hạn báo giả/bỏ sót và chi phí | |
| Số lượt có thể liên hệ mỗi tuần; thiết kế đối chứng nếu đo tác động | |

| Chốt sau khi đủ các kỳ quan sát | Kết quả và đường dẫn bằng chứng nội bộ |
|---|---|
| Bao nhiêu người tự hoàn thành nhập, bao nhiêu nhận biết tuần thiếu lịch | |
| Số kế hoạch khóa trước, số tuần thực có thể đối chiếu, lý do thiếu | |
| MAE và lệch có dấu từng chân tiền/mức dư; so sánh với kế hoạch kế toán | |
| Độ phủ/độ rộng; tuần báo giả/bỏ sót, báo trước; số sự cố độc lập | |
| Số phút và chi phí mỗi kỳ, số lượt dùng, vấn đề người dùng | |
| Quyết định: dùng phiên bản cụ thể / kéo dài pilot / dừng; ai chịu trách nhiệm | |
| Ngày thu hồi quyền và biên nhận xóa/lưu theo thỏa thuận | |
