# 05 · Phát triển và kiểm chứng Agent 1

Thư mục này giữ quy trình làm việc với pipeline đang phục vụ. Kế hoạch WP, prompt bàn giao, nhật ký sprint, tiến độ sinh tự động và báo cáo so sánh các phiên bản cũ đã được loại khỏi tài liệu vận hành.

- [Quy trình thay đổi và kiểm chứng](01_quy_trinh_phat_trien_va_kiem_chung.md): điểm vào mã, chọn phép kiểm và điều kiện hoàn thành.
- [Pipeline hiện tại](../04_AI_Methods/01_pipeline_he_thong.md): nguồn mô tả luồng T0/T9 → T1 + partial → T5/T6 → T10.
- [Nghiệm thu](../03_Evaluation/03_cong_nghiem_thu.md): bằng chứng còn cần trước khi dùng trên SME thật.
- [Vận hành và diễn tập](../06_Pilot/README.md): nhập liệu, cập nhật, dự báo, đối chiếu và UAT.

Các script tổng hợp tiến độ WP/gate nghiên cứu cũ có thể sinh lại tên báo cáo đã bỏ. Không dùng chúng để cập nhật trạng thái nghiệm thu của pipeline hiện tại.
