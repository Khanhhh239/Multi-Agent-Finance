# PLAN_09 integration contracts

Generated by `scripts/validate_plan09.py`: EvaluationCommand, EvaluationState, EvaluationReport, EvaluationArtifact, RuleResultView and Explanation.

Public evaluation IDs identify requests across the whole workflow. `planning_evaluation_id` and `execution_id` identify pinned stage artifacts; original outcome keys/raw traces remain unchanged. Signed pagination binds scope, evaluation, kind, snapshot and page size.

Reports are immutable; latest-head/current-revision flags are computed outside the report. Templates consume validated aggregates and evidence, never calculate a new verdict. Contract errors have no tax conclusion. All outputs currently remain technical-only, with legal release pending.

JSON Schema does not prove ownership, evidence, hashes, approval or replay. Use domain validators and `Workflow.replay` for those checks. [Runbook](../../../docs/agent3/plans/evidence/plan09/demo_runbook.md).
