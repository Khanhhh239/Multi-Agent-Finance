# Issue M2.2 — Semantic Plan Validation Gate

- **Status:** Verified for the M2 component gate
- **Module:** M2 — Semantic Query Planning
- **Depends on:** M2.1, M0.2
- **Module plan:** [Query Planning](../plans/query_planning.md)
- **Contract:** `query.plan-validation.v1`
- **Production scope:** `agent4/planning/validator.py`

## Objective

Niêm phong semantic draft thành immutable validated plan sau khi kiểm tra schema,
capability, authorization và resource limits.

## Tasks

- [x] Implement exact 14-field schema enforcement.
- [x] Chặn SQL/physical identifiers trong draft.
- [x] Validate snapshot/as-of và flow/range semantics.
- [x] Validate dates, `max_days <= 750`, dimensions, filters, operators và values.
- [x] Enforce `1 <= top_k <= 100` và `1 <= row_cap <= 1000`.
- [x] Gắn tenant, catalog hash, policy hash và applied defaults.
- [x] Thêm contract và SQL-injection regression tests.

## Acceptance criteria

- Chỉ validated plan đúng trust boundary mới được downstream chấp nhận.
- Injection qua dimension/filter bị fail-closed.
- Invalid time modes/ranges/limits bị reject đúng error.
- Output hashes/context không lấy từ untrusted user payload.
