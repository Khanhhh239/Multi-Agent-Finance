- **Status:** Verified
- **Module:** M3 — SQL Engine
- **Depends on:** M3.2, M1.4

## Objective

Chỉ thực thi safety-approved bound query trên DuckDB read-only, có timeout,
outage handling, normalized result metadata và tích hợp L3 SQL Result Cache khóa
theo `(tenant_id, catalog_hash, data_watermark, query_fingerprint, row_cap)`.

## Tasks

- [x] Implement `execute_safe_sql()` và reject input chưa qua safety gate.
- [x] Mở DuckDB với `read_only=True`.
- [x] Enforce timeout và map outage thành retryable `temporarily_unavailable`.
- [x] Chuẩn hóa columns, rows và `data_watermark`.
- [x] Tích hợp L3 SQL Result Cache (`agent4/core/cache.py`) với giới hạn 200 dòng mỗi entry.
- [x] Thêm integration tests trên warehouse thật, write-block test và L3 cache isolation/freshness tests.

## Acceptance criteria

- Executor không nhận raw/unvalidated query.
- Database write bị chặn ở connection level.
- Timeout/outage không lộ database internals và có đúng retry semantics.
- Management/tax fixture trả đúng independently recorded values trong module plan.
- L3 SQL Cache cô lập tuyệt đối theo `tenant_id` và tự động mất hiệu lực khi `data_watermark` hoặc `catalog_hash` thay đổi.
