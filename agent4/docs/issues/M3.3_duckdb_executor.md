## Objective

Chỉ thực thi safety-approved bound query trên DuckDB read-only, có timeout,
outage handling và normalized result metadata.

## Tasks

- [ ] Implement `execute_safe_sql()` và reject input chưa qua safety gate.
- [ ] Mở DuckDB với `read_only=True`.
- [ ] Enforce timeout và map outage thành retryable `temporarily_unavailable`.
- [ ] Chuẩn hóa columns, rows và `data_watermark`.
- [ ] Thêm integration tests trên warehouse thật và write-block test.

## Acceptance criteria

- Executor không nhận raw/unvalidated query.
- Database write bị chặn ở connection level.
- Timeout/outage không lộ database internals và có đúng retry semantics.
- Management/tax fixture trả đúng independently recorded values trong module plan.
