## Objective

Xây dựng nguồn chân lý duy nhất cho metric definitions, capability, visibility
và catalog fingerprint.

## Tasks

- [ ] Khởi tạo `MetricCatalog` với 15 definitions từ module plan và lưu bản sao
  bất biến.
- [ ] Tính `catalog_hash` deterministic từ toàn bộ metric definitions.
- [ ] Implement `get()`, `contains()`, `get_capability()`,
  `list_visible_metrics()` và `get_catalog_hash()`.
- [ ] Chặn metric draft, unverified, ngoài `allowed_metrics` hoặc không tương
  thích `allowed_views` khỏi production visibility.
- [ ] Thêm production-facing catalog tests.

## Acceptance criteria

- Getter không làm lộ mutable internal state.
- Unknown metric trả đúng contract error.
- Chỉ metric `approved` và `verified_handler=true` được visible.
- Visibility tôn trọng view và metric authorization.
- Cùng input cho cùng hash; thay đổi definition hoặc SQL expression làm đổi hash.
