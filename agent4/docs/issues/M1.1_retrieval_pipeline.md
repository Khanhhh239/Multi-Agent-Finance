## Objective

Tạo retrieval pipeline sinh và xếp hạng candidate metrics đã được catalog quản
trị, không quyết định metric cuối cùng.

## Tasks

- [ ] Implement `EmbeddingProvider` và `build_metric_documents()`; không đưa
  draft metrics, SQL hoặc raw financial data vào documents.
- [ ] Implement dense và lexical retrieval với kiểm tra catalog hash/dimension.
- [ ] Implement RRF fusion với `rrf_k=60`, dedup và bảo toàn source scores.
- [ ] Implement metadata reranking mà không thêm candidate mới.
- [ ] Implement orchestrator với ba trạng thái `candidates_found`,
  `empty_candidates`, `retrieval_unavailable`.
- [ ] Thêm production-facing unit/contract tests.

## Acceptance criteria

- Candidate IDs luôn thuộc approved catalog.
- Provider outage được phân loại retryable retrieval failure.
- Fusion/reranking deterministic và giữ bất biến candidate set.
- Empty/unavailable paths phân biệt rõ ràng.
