# Issue M3.1 — Deterministic SQL Compiler

- **Status:** Planned
- **Module:** M3 — SQL Engine
- **Depends on:** M2.2, M0.2
- **Module plan:** [SQL Engine](../plans/sql_engine.md)
- **Contract:** `sql.compiler.v1`
- **Production scope:** `agent4/sql/compiler.py`

## Objective

Biên dịch duy nhất từ validated plan sang deterministic parameterized bound
query có row cap và fingerprint.

## Tasks

- [ ] Implement `compile_sql(validated_plan, catalog, row_cap=1000)`.
- [ ] Reject raw string/draft/unvalidated input và catalog hash mismatch.
- [ ] Map business views, metrics và dimensions qua allowlists.
- [ ] Parameterize all values; thêm deterministic grouping/ordering và `LIMIT ?`.
- [ ] Tạo stable query fingerprint từ SQL template và params.
- [ ] Thêm compiler contract tests.

## Acceptance criteria

- Compiler không nhận unvalidated plan.
- Không user value nào được nối trực tiếp vào SQL.
- Query luôn deterministic và có bounded row cap.
- Chỉ approved relations/columns từ mappings được sinh ra.
