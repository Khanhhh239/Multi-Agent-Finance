## Objective

Fail closed mọi bound query không vượt qua đủ bảy chốt SQL safety trước khi kết
nối database.

## Tasks

- [ ] Implement `validate_sql_safety()`.
- [ ] Enforce read-only và single-statement.
- [ ] Enforce approved relations/columns và parameterization.
- [ ] Enforce row cap, tenant scope và catalog hash.
- [ ] Trả allowed result với safe bound query hoặc structured rejection.
- [ ] Thêm regression tests cho từng attack variant.

## Acceptance criteria

- Cả bảy checks phải pass; thiếu evidence là reject.
- DML/DDL, multi-statement, unknown relation/column và literals bị chặn.
- Tenant/catalog mismatch và missing row cap bị chặn.
- Public error không lộ raw SQL hoặc sensitive data.
