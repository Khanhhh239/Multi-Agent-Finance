- Cả bảy checks phải pass; thiếu evidence là reject.
- DML/DDL, multi-statement, unknown relation/column và literals bị chặn.
- Tenant/catalog mismatch và missing row cap bị chặn.
- Public error không lộ raw SQL hoặc sensitive data.
