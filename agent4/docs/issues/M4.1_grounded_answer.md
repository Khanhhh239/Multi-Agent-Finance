## Objective

Validate query results, generate claims grounded in source cells and reject or
fallback from hallucinated/unsafe answer drafts.

## Tasks

- [ ] Implement `validate_result()` với schema/type/semantic checks.
- [ ] Handle ratio zero denominator, partial watermark và no-data states.
- [ ] Implement bilingual deterministic `generate_grounded_answer()` với source references.
- [ ] Implement `validate_answer()` và deterministic safe fallback.
- [ ] Neutralize indirect prompt injection from database content.
- [ ] Thêm result, answer và A8 security tests.

## Acceptance criteria

- NaN/Infinity/duplicate columns bị reject.
- Ratio undefined, partial và no-data được phân loại đúng.
- Mọi numerical claim truy vết được tới result cells.
- Unsupported causal explanations và injected instructions bị reject.
- Rejected drafts không được trả ra ngoài; fallback an toàn được dùng.
