## Objective

Thiết lập cấu hình nền, chuẩn hóa lỗi an toàn, intake boundary và auth/runtime
context chỉ lấy quyền từ nguồn server.

  question limit, row cap và query timeout theo module plan.
- [ ] Implement `ContractError`, `_sanitize_message()`, `_sanitize_details()` và

- [ ] Implement `query_intake()` cho `v1`, `vi-VN`/`en-US`, giới hạn 500 ký tự,
  normalization và input immutability.
- [ ] Implement `build_auth_context()` và `build_runtime_context()` từ IdP claims
  và server policy; bỏ qua auth claims trong request body.
- [ ] Thêm production-facing tests cho các contract trên.

## Acceptance criteria

- Unknown/missing fields bị reject tại boundary.
- Public error không lộ SQL, stack trace, credentials hoặc raw financial rows.
- Intake giữ nguyên input và chuẩn hóa câu hỏi đúng contract.
- Auth fail-closed khi claims/policy thiếu hoặc rỗng.
- `policy_hash` deterministic và quyền không lấy từ client payload.
