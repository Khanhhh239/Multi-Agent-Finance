# Issue M1.4 — Multi-Tier Governed Cache (L1 Artifact & L2 Embedding/Selection Cache)

- **Status:** Verified on the 140-case structured development preset. Default Qwen3 preset remains unverified.
- **Module:** M0 / M1 — Core & Metric Selection
- **Depends on:** M1.3
- **Module plan:** [Core and Catalog](../plans/core_and_catalog.md), [Metrics Selection](../plans/metrics_selection.md)
- **Contracts:** `cache.governed.v1`, `metric.embedding-provider.v1`, `metric.retrieval.orchestrator.v1`, `metric.validation.v1`
- **Production scope:** `agent4/core/cache.py`, `agent4/metric_selection/index.py`, `agent4/metric_selection/embedding.py`, `agent4/metric_selection/fewshot.py`, `agent4/metric_selection/orchestrator.py`, `agent4/metric_selection/recovery.py`

## Objective

Giảm thời gian nạp lặp lại các tài nguyên tĩnh từ đĩa (`.npz` vector index, `example_bank.jsonl`) và cắt giảm độ trễ gọi Ollama Embedding / LLM Selection thông qua bộ nhớ đệm `LRUTTLCache` có giới hạn RAM nghiêm ngặt, bảo toàn tính bất biến và cô lập tuyệt đối theo `tenant_id`, `policy_hash`, `catalog_hash`.

## Tasks

- [x] Implement `LRUTTLCache` và `build_scoped_cache_key()` trong `agent4/core/cache.py` với giới hạn `max_entries`, `ttl_seconds`, `max_bytes_budget`, `max_rows_per_entry`, và cơ chế `clone_on_read=True` (`copy.deepcopy`).
- [x] Gắn **L1 Artifact Memory Cache** vào `load_index()` (`agent4/metric_selection/index.py`) và bộ nạp `example_bank.jsonl` (`agent4/metric_selection/fewshot.py`) khóa theo `(path, mtime_ns, catalog_hash)` với `maxsize=2`.
- [x] Gắn **L2a Query Embedding Cache** vào `EmbeddingProvider.embed()` (`agent4/metric_selection/embedding.py`) khóa theo câu hỏi chuẩn hóa, model và phạm vi cấp quyền.
- [x] Gắn **L2b Retrieval & Validated Selection Cache** vào truy hồi và `select_metrics_with_recovery()`. Khóa gắn phạm vi cấp quyền, locale, requested view, cấu hình và phiên bản artifact. Không cache trạng thái lỗi tạm thời (`retrieval_unavailable`, `temporarily_unavailable`).
- [x] Cung cấp `cache.stats()` (`hits`, `misses`, `evictions`, `active_entries`, `estimated_memory_kb`) để phục vụ observability.
- [x] Thêm bộ kiểm thử `tests/contracts/test_cache_governance.py`.

## Acceptance criteria

- L1/L2 cache hit trả về kết quả giống hệt 100% so với cache miss và không làm biến đổi dữ liệu trong cache khi caller sửa đổi dict trả về.
- Không bao giờ rò rỉ dữ liệu hoặc kết quả chọn metric giữa hai `tenant_id`, `policy_hash`, `allowed_views` hoặc `allowed_metrics` khác nhau.
- Tự động vô hiệu hóa (cache miss) ngay khi `catalog_hash` hoặc file index thay đổi.
- Giới hạn phần tử (`max_entries`), giới hạn số dòng (`max_rows_per_entry`) và `ttl_seconds` hoạt động đúng chuẩn LRU + TTL.
