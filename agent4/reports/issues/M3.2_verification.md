## Xác minh

Giả thuyết của lượt triển khai đầu tiên là so khớp template xác định có thể kiểm tra toàn bộ câu lệnh trước khi kết nối DuckDB. Các lệnh dưới đây exit 0.

```bash
make format-check lint typecheck test-sql test-security PYTHON=.venv/bin/python CHECK_PATHS='agent4/sql tests/contracts/test_compiler_safety_execution.py'
make verify PYTHON=.venv/bin/python CHECK_PATHS='agent4/sql tests/contracts/test_compiler_safety_execution.py'
git diff --check
```

SQL contract có 35 ca, gồm 20 ca gọi safety gate production. Security suite có 12 ca. Scoped verify chạy format, lint, compile và toàn bộ 485 test. Full test suite chạy ngoài sandbox vì worker thread của các test async bị treo trong sandbox. Issue dùng deterministic security fixtures theo đặc tả, chưa có số liệu benchmark AI.

`make format-check PYTHON=.venv/bin/python` toàn repo exit 2 do 16 file ngoài phạm vi cần format, cùng số lượng với baseline M1.4.
