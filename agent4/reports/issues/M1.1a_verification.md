```bash
.venv/bin/python - <<'PY'
from pathlib import Path
from statistics import median
from tempfile import TemporaryDirectory
from time import perf_counter_ns

from agent4.metric_selection.catalog_adapter import build_canonical_catalog
from agent4.metric_selection.config import load_config
from agent4.metric_selection.embedding import EmbeddingProvider
from agent4.metric_selection.index import build_index, load_index

catalog = build_canonical_catalog()
provider = EmbeddingProvider(load_config().embedding)
catalog_hash = catalog.get_catalog_hash()
build_ms, load_ms = [], []
with TemporaryDirectory() as tmp:
    path = Path(tmp) / "index.npz"
    for _ in range(30):
        start = perf_counter_ns()
        built = build_index(catalog, provider, path)
        build_ms.append((perf_counter_ns() - start) / 1e6)
        start = perf_counter_ns()
        loaded = load_index(path, catalog_hash=catalog_hash, embedding_provider=provider)
        load_ms.append((perf_counter_ns() - start) / 1e6)
    size = path.stat().st_size
    print(f"{provider.model_id}@{provider.model_version} {catalog_hash} shape={loaded.vectors.shape} {size} bytes")
    for name, samples in (("build", build_ms), ("load", load_ms)):
        print(f"{name} first={samples[0]:.3f} ms median={median(samples):.3f} ms max={max(samples):.3f} ms")
    assert built.vectors.shape == loaded.vectors.shape == (66, 768)
    assert max(load_ms) < 10 and size < 1_000_000
PY
```

## Decisions and limits

- The offline builder uses a read-only approved catalog snapshot. Request-time visibility continues through `list_visible_metrics(auth_context)`.
- The Issue specifies JSON metadata inside the archive. This keeps metadata and vectors together during replacement. The README references a missing build script, so verification used the production Python API.
- The configured `model_version` represents the embedding revision. Update it when model weights change under the same model tag. Rebuild or use separate archive paths for changes to document locale.
- Performance figures describe this machine and its filesystem cache. Live Ollama behavior and AI quality experiments E1 and E2 were outside this verification run.
