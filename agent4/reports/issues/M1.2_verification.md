## Decisions and limits

- The legacy bank remains in its existing JSONL format. The loader labels it `repository_curated` and normalizes it in memory. The checked-in bank is Vietnamese, so a locale without matching examples uses the empty-example path. For legacy ambiguous examples, the alternatives identified in metadata must also be present in the production candidate set.
- The budget uses the larger of the declared count and a UTF-8 byte estimate for each serialized prompt item. This is an offline approximation. Pattern-based injection screening complements the requirement to curate and approve the bank.
- Explicit adapters pin E3 to static and E4 to hybrid. The default selection remains zero-shot. For a future ablation, the runtime `AGENT4_METRIC_SELECTION_CONFIG` and runner `--config` should identify the same configuration, and the configured bank should match the runner's `--example-bank`.
- No live Ollama calls or E3/E4 quality runs were made. Exact Set Match, Micro F1, multi-metric regressions, latency, and cost for the ablations are unmeasured. The E0 and E2 selection baseline summaries named by the issue are absent from this checkout. The existing retrieval artifacts do not establish G3.
