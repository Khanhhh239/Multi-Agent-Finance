# Ablation report

Available offline comparisons: lexical, hashing-dense, hybrid RRF, expansion
and metadata reranking, all over the same 66-ID catalog and seed split. Full
catalog mode and few-shot strategies exist in the prior metric-selection
pipeline.

Not qualified: causal E0–E6 LLM plan comparison. No provider was available and
using a fixed mock would be fake evidence. The report therefore records that
gate as BLOCKED rather than manufacturing token, cost or accuracy values.
